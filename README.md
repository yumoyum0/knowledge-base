# Knowledge-Base

A minimal Electron desktop app for managing local markdown/text documents with Q&A search.

## Quick Start

```bash
# Linux / macOS
./init.sh

# Windows PowerShell
./init.ps1
```

Both scripts install dependencies, run tests (75 assertions), and run the linter.

To launch the app: `npm start`
